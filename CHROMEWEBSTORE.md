# Chrome Web Store listing
**Name**: Inky — Smart Dark Mode & Night Light
**Short description**: Smart dark mode that understands icons and images, plus a blue-light night filter. Minimal, fast, private.
**Permissions**
| Permission | Why |
|---|---|
| `storage` | Save settings, palettes and per-site rules locally |
| `scripting` | Inject into tabs already open at install/update |
| Host `<all_urls>` | Apply dark mode / night light on any site; service worker reads icon files the page already loads to detect dark icons |
**Privacy**: no data collected or transmitted; all analysis is on-device.
